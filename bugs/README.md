## Правила репозитория, которые нельзя нарушать

* **Никогда не коммитить** `backend/.env` (там ключ Anthropic), keystore,
  `local.properties`. Разрешён только `.env.example`.
* Сообщения коммитов — по-русски.
* Каждая правка подтверждается тестом, **падающим на старом коде**. Проверять
  это буквально: откатить правку в копии дерева и убедиться, что тест красный.
