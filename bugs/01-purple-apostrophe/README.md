# Проверка «пурпурной прозы» ловила слова через раз

**Это настоящий дефект, а не косметика, и он старше остальных правок в этом
архиве.** Его стоит взять, даже если две другие правки отложат.

## В чём дело

У продукта есть список слов, которыми Альма говорить не должна, — «энергия»,
«путь души», «истинное я», `l'univers`. Его собрали после того, как первая
бесплатная глава русской карты вышла под заголовком «Ядро — что во мне
настоящее, под всем остальным?»: ровно то, чего владелец не хотел.

Список сверяется с текстом модели простым вхождением подстроки:

```python
lowered = text.lower()
return [word for word in _PURPLE.get(base, ()) if word in lowered]
```

А апостроф модель ставит тот, какой захочет. Для `in` строки `l'univers`
(машинописный) и `l’univers` (типографский) — разные. Значит **записи с
апострофом не ловились примерно в половине случаев** во французском и
итальянском.

Заметить это было нельзя ничем: проверка не падает и не жалуется — она молча
пропускает. Единственный признак — текст, который должен был быть отвергнут,
приходит к читателю.

## Как нашлось

Косвенно. Французскую типографику приводили к «’», дошли до этого списка — и
стало видно, что список, приведённый вместе с текстом, перестанет ловить
машинописный апостроф. То есть беда симметрична и существовала всегда, просто
с другой стороны.

## Что сделано

Сравнение приведено к одной форме с обеих сторон: и текст модели, и слово из
списка складываются к машинописному апострофу перед сверкой.

```python
def _fold_apostrophes(value: str) -> str:
    return value.replace("’", "'").replace("ʼ", "'")
```

`ʼ` — «модификатор-апостроф», третий знак, который встречается в
машинных текстах.

Список французских слов заодно приведён к типографскому апострофу — теперь это
безразлично, но так он совпадает с остальным французским в продукте.

## Тест

`backend/tests/test_ai.py::test_the_purple_list_catches_both_apostrophes`

Проверяет обе формы и что результат для них одинаков. **На старом коде падает**
на кудрявой форме.

## Проверено вручную

```
"Le chemin vers l'univers" -> ['l’univers']
"Le chemin vers l’univers" -> ['l’univers']
```

## Чего эта правка НЕ делает

Не расширяет список слов. Не трогает другие языки списка. Не меняет, что
происходит при срабатывании, — только то, срабатывает ли оно вообще.
