# Скриншоты — web-превью

Сняты **из Flutter-веб-сборки** (Chrome, Playwright), не с устройства. Композиция,
вёрстка и текст — настоящие; человек — вымышленная **Sofia, 14 марта 1994, 07:42, Милан**
(из `mobile/store/SCREENSHOTS.md`). Карта посчитана бэкендом по-настоящему: Солнце — Рыбы,
Луна — Овен, Восходящий — Овен.

**Это НЕ стор-ассеты.** App Store / Google Play принимают только девайс-рендер (iOS —
только на macOS-симуляторе; Android — на эмуляторе/устройстве). Здесь — веб, для показа.
