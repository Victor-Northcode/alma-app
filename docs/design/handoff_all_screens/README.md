# Эталон всех экранов Alma + спека по каждому

Открыть `Alma - All Screens (EN).dc.html` двойным кликом (структуру папок не менять: html грузит `assets/opt/` и `ios-frame.jsx`). Нужен интернет — шрифты с Google Fonts. У каждого экрана на холсте золотой бейдж **S1…S54** — так на них ссылаются в задачах.

Куда какой экран встраивается — `screen-map.md`. Деньги — `money-map.md`. Остальные спеки: `pill-spec.md`, `chat-spec.md`, `meta-line-spec.md`, `plates-map.md`, `today-reading-spec.md`, `strings-batch1/2.md`, `SKILL.md` (токены для Claude Code).

**Правило при расхождениях:** прав холст; если старый экран спорит с люкс-эталоном — правы **S44 · S45 · S46 · S47 · S41**.

## Общий каркас (действует на всех экранах)
- Фон ночи: фото `bg-sky.jpg` + скрим (сверху rgba(10,13,28,.5) → снизу rgba(7,10,22,.94)) + 4–6 мерцающих точек-звёзд.
- Паддинг 22 по бокам, контент от 64 сверху. Таб-бар 84 (компакт 72). Кнопки: золотая 56 · вуаль 52 · контур 50, радиус = высота/2. Поля 54/27.
- Типографика: Playfair — дисплей (имена, титулы, цифры, мета-строка); **Lora** — всё, что читают дольше вздоха; Golos — интерфейс, подписи, юридика.
- Максимум **одна золотая кнопка на экран**. Небо движется — интерфейс нет.
