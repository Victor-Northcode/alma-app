# Alma — карта экранов: где живёт каждый S

Куда помещается каждый экран холста, откуда открывается и что открывает сам.
Статусы: **финал** — собирать это; **состояние** — вариант того же места; **легаси** — заменён люкс-версией, держим для сверки механики.

## 0. Граф одним взглядом

```
S12 Launch
 ├─ первый запуск → Journey: S13 имя → S35 о себе → S14 дата → S15 время → S16 место
 │                  → [интеррапт S38 DST, если время неоднозначно] → S17 церемония
 │                  → S39 пре-аск пушей → S44 вход (можно пропустить)   [S37 дверь после церемонии снята: первый оффер — V1]
 │                  → таб Today
 └─ повторный запуск → таб Today (S45 подписчик / S2-механика фри)

Таб-бар: Today · My systems · Alma · Settings
Деньги: закрытая глава → V2 дверь системы · «все планы» → V8 · живой блок → V6
        (лестница S8, архив S43 и добор сняты — см. раздел 5)
```
