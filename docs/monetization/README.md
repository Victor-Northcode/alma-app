# Монетизация v3 — пакет для разработчиков

Порядок чтения: **этот файл** → `monetization-v3-spec.md` (что на каждом экране) → холст `Alma - Monetization v3.dc.html` (открыть в браузере) → `alma-monetization-v3-tz.md` и `alma-monetization-v3-tech-appendix.md` (продукт и бэкенд).

Холст открывать двойным кликом, структуру папок не менять — html грузит `assets/opt/` и `ios-frame.jsx`. Нужен интернет: шрифты с Google Fonts.

## Что внутри
- `Alma - Monetization v3.dc.html` — 17 экранов с бейджами: **V0** квиз · **V1** оффер в конце бесплатной главы · **V2** дверь · **V3** «что дальше» · **V4** тизер пары · **V5** мои пары · **V6** подписка · **V7** квота вопросов · **V8** все планы · **V9** cancel-save · **W1** главный по NBO · **W2** ввод партнёра · **W3** отчёт по паре · **W4** заметка дня · **W5** подписчик без пейволла · **W6** состояния покупки · **W7** пуши. Плюс карточка **VR** — что v3 убивает в старых файлах.
- `monetization-v3-spec.md` — карта «бейдж → поверхность ТЗ → триггер → SKU», маршрутизация `PaywallRouter`, спека по каждому экрану, копирайт-инварианты, список удаляемого, приёмка глазами.
- ТЗ и техприложение — исходные документы.
- `assets/opt/`, `ios-frame.jsx`, `support.js` — чтобы холст открывался офлайн. В приложение не переносить.

## Три правила, которые проверяются на каждом экране
1. Одна цена на экране: одна золотая кнопка + не более одной тихой ссылки. Лестница цен — только на V8.
2. Разовое и подписка не смешиваются: на разовых экранах слово «renew» вне закона, на подписочных абзац продления обязателен над кнопкой.
3. Внутри оплаченного — ноль коммерции (W3, W5).

## Открытое решение для заказчика
Пилюля «All of Alma» над Today — проактивный оффер на каждом экране, что противоречит правилу «≤1 проактивного оффера за сессию». Рекомендация: снять, живое продавать из закрытых блоков заметки дня (W4 → V6).
