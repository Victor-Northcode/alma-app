# Экраны порта против дизайн-проекта

Один ряд на экран макета. **Статус ставится только по увиденному на
устройстве** — снимок экрана рядом с эталоном. «Не сверял» значит именно это:
код может быть на месте, но глазами не проверено, и записывать такое в
«готово» нельзя.

Файл ведётся между заходами, чтобы не проверять одно и то же дважды.

## Что уже исправлено по ходу

- Вклейки глав (`PlateArch`) стояли только в отладочной витрине — встали в
  главу, витрина удалена.
- Кнопка шага анкеты была плоским золотом с тёмной подписью — заменена
  текстурной с радиусом 15, как во всех шести её появлениях.
- Список найденных городов был капсулами — стал списком с золотой звёздочкой у
  лучшего совпадения.
- Поле в покое и поле под курсором различаются заливкой, как в эталоне.
- Знак: кольца были втрое шире ромба, отношение приведено к 1,73.
- Колесо даты: нетронутый барабан не отдаёт значение; ключи против
  переиспользования состояния между шагами.
- Отступ под таб-баром считал бар дважды (164 точки вместо 86); завеса бара
  резала строку пополам.
- «Мои системы» показывали список строк с надписью «open» — стали карточками с
  артом по две в ряд, пропорция 172×156 из эталона; закрытая система не
  запирается замком, а приглушается, потому что рассчитано всё.
- Таб-бар оставался пергаментным поверх ночного «Сегодня»: признак чтения
  поднимает страница главы, а `PageView` её не выбрасывает — она
  перерисовывалась и поднимала флаг снова, уже после ухода с неё. Теперь
  пергаментным бар бывает только на вкладке «Мои системы».
